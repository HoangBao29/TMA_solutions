# TKFilm - AI-Powered Movie Recommendation System

TKFilm is a modern mobile application built with **React Native** and **Flask**, designed to provide highly personalized movie recommendations using state-of-the-art **Attention Autoencoder (RSAttAE)** models.

---

## ✨ Key Features

- **Smart Onboarding**: New users rate a few movies to kickstart the AI recommendation engine.
- **AI Recommendations**: Utilizes dual Attention Autoencoder models (User & Movie) trained on the MovieLens dataset to find perfect matches.
- **TMDb Integration**: Real-time movie search, posters, trailers, and detailed information powered by The Movie Database API.
- **Dynamic Personalization**: Recommendations update instantly as you rate or interact with movies.
- **Premium UI**: Sleek, modern interface with glassmorphism effects, smooth animations, and intuitive navigation.

---

## Tech Stack

### Frontend
- **Framework**: React Native (Expo)
- **Navigation**: Expo Router (File-based routing)
- **Styling**: Vanilla CSS-in-JS
- **State Management**: Zustand / Hooks

### Backend
- **Framework**: Flask (Python)
- **AI/ML**: PyTorch
- **Models**: RSAttAE (Information-Aware Attention Autoencoder)
- **Data Enrichment**: TMDb API Service

## Getting Started

### Prerequisites

- **Node.js**: 20+
- **Python**: 3.8+
- **TMDb API Key**: (Included in the project for development)

### 1. Clone the repository
```bash
git clone <repository-url>
cd tkfilm
```

### Quick Start (Linux/macOS)
The project includes a convenience script that handles environment checks, dependency installation, and starts the backend service.

```bash
chmod +x start.sh
./start.sh
```

### Manual Setup
If you prefer to set up the components manually:

#### 1. Setup Backend (Flask)
The backend handles AI inference and TMDb data enrichment.

```bash
cd service_AI
# Create and activate virtual environment (optional but recommended)
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the backend
python app.py
```
*The backend will run on `http://localhost:5000`.*

### 3. Setup Frontend (React Native)
```bash
cd ..
# Install dependencies
npm install

# Start Expo development server
npx expo start
```
*Note: If testing on a physical device, update the `BACKEND_URL` in `app/service/api.ts` to your machine's local IP address.*

## AI Model Architecture (RSAttAE)

TKFilm employs a sophisticated recommendation logic:
1. **User Profile**: Created by a weighted average of movie embeddings based on your ratings.
2. **Latent Space**: Movies and Users are mapped to a 64-dimensional space using Attention Layers that focus on important features (genres, release year).
3. **Similarity**: Recommendations are generated by calculating the cosine similarity between your profile and thousands of movies in real-time.

For a deeper dive into the AI models, check out [AI_MODELS_EXPLAINED.md](./AI_MODELS_EXPLAINED.md).
